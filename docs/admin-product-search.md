# Поиск товаров в админке

Таблица `/admin/products` передаёт поисковый запрос целиком в `AdminProductSearch`, а не запускает общий поиск отдельно из каждого поискового столбца/слова.

1. Код 1С вида `УТ-00009721` ищется только как код номенклатуры. Поддерживаются `UT`, другой регистр, пробелы, типографские тире, отсутствие дефиса и краткая запись `УТ-9721`. Проверяются кеш номенклатуры и подтверждённые связи источника `onec`, включая исполнения с характеристиками. Если связи нет, чужая карточка с таким же числовым окончанием не подставляется.
2. Точный внутренний SKU имеет приоритет. Старый SKU объединённой карточки ведёт на её каноническую карточку.
3. Для артикулов с цифрами проверяются исходный/нормализованный/компактный артикул и каталожный код поставщика, внешний артикул интеграции, заводской артикул из номенклатуры 1С.
4. Для названий остаётся существующий поиск каталога с поддержкой словоформ и раскладки. Фильтры таблицы и исключение архивных товаров сохраняются.

Это поиск менеджера; внутренние коды не добавляются в публичные подсказки покупателю. Поиск ничего не создаёт и не меняет связи, цены или остатки.

Для равенства по `products.sku` добавлен отдельный B-tree индекс: имеющийся составной FULLTEXT `name,sku` его не заменяет. Для поиска по компактному артикулу среди всех поставщиков добавлен индекс, не требующий предварительно указать `supplier_id`. Существующие индексы проверяются перед созданием.

Колонка 1С использует заранее загруженные связи и элементы номенклатуры, кешируя результат на время отрисовки таблицы. Это убирает повторные запросы каждой ячейки. Для редких связей с характеристиками без прямого `onec_items.product_id` остаётся один запрос по ключу номенклатуры, а не повторные запросы каждой ячейки.

Проверки: `AdminProductSearchTest`, `SupplierArticleSearchTest`; отдельная тестовая база. Предварительный замер на рабочем каталоге до установки новых индексов: код `УТ-00009721` — старый поиск 302,5 мс и ошибочный товар 32603, новый 7,1 мс и правильный товар 16396. Это время самого поиска, не всей HTML-страницы.
