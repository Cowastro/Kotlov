# ОмЭнерго: онлайн-прайс и каталог

Источник: https://docs.google.com/spreadsheets/d/1drIsDi5VSX4NCZgc4XiCjf95XkQcZw7jRIufriq0rSA/edit?gid=1161827566#gid=1161827566

Подтверждено владельцем 16.10.2026: Д2 — закупка BYN с НДС, МРЦ — розница. Прайс поставщика только читается. Контакты проверены по вкладке «Информация» и https://omenergo.by/.

Первичная проверка: `php artisan supplier:sync-omenergo --dry-run`.

После просмотра отчёта: `php artisan supplier:sync-omenergo --apply --confirm-pricing --match-existing`. Создание недостающих карточек — отдельный запуск с `--create-new --update-content`. Новые карточки не публикуются до проверки изображений и характеристик.

Ежедневно в 07:45 Europe/Minsk выполняется `supplier:sync-omenergo --apply`: только ранее привязанные товары, без создания карточек, AI, парсинга фотографий или переписывания описаний. Используется блокировка параллельных запусков. Ошибка загрузки, изменение заголовков, дубликаты артикулов и подозрительно короткий прайс останавливают импорт до изменения цен.

Наличие:

- `*` / `**` / `***` — «В наличии», количество неизвестно;
- «Нет в наличии» — нулевой остаток этого поставщика;
- «Под заказ» — количество и срок требуют подтверждения.

Обновлено по указанию владельца 16.10.2026: публичные статусы единые, без слов «у поставщика». Свежий известный остаток — «В наличии: N шт.» (или единица товара), подтверждённое наличие без количества — «В наличии», неподтверждённое — «Доступно к заказу». Звёздочки не превращаются в фиктивные штуки. Число берётся из свежего активного канала, не из устаревшего поля-сводки. Дубли одной карточки в одном источнике не суммируются; числовые интеграции имеют приоритет перед старым каналом поставщика. Ручной остаток и ценовой запрет имеют приоритет. Изменение надписей само по себе не ослабляет проверки заказа: без положительного численного остатка сохраняется подтверждение менеджером до отдельного разрешения владельца. Исчезнувшие строки перестают подтверждать наличие только у ОмЭнерго; другие поставщики и их история сохраняются.

Существующие карточки при точном совпадении нужно сохранять. Для исправления прежней замены дублями: `supplier:sync-omenergo --restore-matching-legacy --dry-run`, затем после проверки счётчиков `--restore-matching-legacy --apply`. Однозначно совпасть должны бренд, категория, нормализованная модель и исполнение. Цены сверяются со свежим прайсом; требуется проверенное фото. Другие каналы, ручной остаток и неоднозначность блокируют перенос. Исходные ID, SKU, slug, история и популярность сохраняются; привязка, актуальные цены, описание, фото и документы переносятся на оригинал. Дубль архивируется, с его адреса создаётся 301 на оригинал. Резервный снимок сохраняется до изменений в приватный storage; операция транзакционная и повторяемая. Разные исполнения не объединяются.

Архив исходного CSV и снимок изменяемых карточек/связей сохраняются в приватном storage, отчёт сопоставления — в `storage/app/reports/omenergo/`. Подобные модели, конфликт бренда, архивные карточки и несколько строк на одну карточку требуют ручной проверки.

В исходном прайсе ACH 10000 имеет ошибочное «8000 ВА» в описании: конфликт отмечается, неподтверждённая мощность в текст карточки не переносится.

Обогащение: `supplier:enrich-omenergo --dry-run --limit=20`, затем `--apply --publish-complete`. Парсер работает только с проверенными HTTPS-доменами ОмЭнерго и официального каталога Энергия, скачивает только изображения подходящего формата и размера. В официальном каталоге используются точные заводские артикулы; расхождение мощности модели блокирует перенос. Е0101-0242 в прайсе назван Expert 800, а в официальном каталоге относится к Expert 350 (220В). Такую строку нельзя публиковать автоматически.

Фотоархив Яндекс.Диска из вкладки «Информация» возвращает 404. Для изображений используются только карточки с проверенной моделью. Цены российского каталога никогда не переносятся в BYN-прайс. Подробные отчёты остаются на сервере; GitHub получает только числовые итоги без данных карточек и контактов. Единственное отдельно разрешённое владельцем исключение — `--dry-run --review-two`: ровно две спорные строки и четыре поля (артикул, название, ID карточки, кандидат), без цен и контактов, приватный артефакт со сроком хранения 1 день. Изменение числа строк останавливает экспорт.

Технические таблицы ОмЭнерго читаются в двух- и трёхколоночном формате с сохранением единиц и из отдельного блока характеристик модели. Старая серия Гарант проверяется по мощности и напряжению батареи; Pro — по точному артикулу, модели, мощности ВА и напряжению АКБ. Pro Online использует выбранные заводские варианты 24/48 В, а не страницу семейства с вариантом 12 В по умолчанию. Фотографии и PDF скачиваются локально; публикация требует реального локального изображения минимум 200 px, проверенных характеристик и отсутствия конфликтов. Старые несвязанные карточки допустимо архивировать после сверки актуальной замены; остатки и другие поставщики не затрагиваются.

Архивирование заменённых карточек — только вручную: сначала `supplier:sync-omenergo --dry-run --archive-replaced`, затем при проверенных кандидатах `--apply --archive-replaced`. Требуется единственная активная замена OMENERGO той же модели, бренда и категории с положительной ценой, характеристиками и реальной локальной фотографией минимум 200 px. У старой карточки не должно быть никаких товарных каналов, назначенного поставщика, ручного остатка/закупки или признака наличия. Неоднозначные модели не архивируются. Снимок исходных полей и ID замены сохраняется только в приватном storage; изменяется только `is_archived`, без удаления истории. РСН 10%, HP 5% и Neo — разные исполнения, сходства названия недостаточно.
