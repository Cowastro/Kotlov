# Обновление BANIA.by

Штатное расписание: раз в сутки в 07:10 по часовому поясу синхронизации поставщиков. Источник — два файла в папке поставщика на Google Drive: «Наличие товара (без фото).xlsx» (закупка с НДС и наличие) и «Рекомендуемые розничные цены.xlsx» (розница). Закупочная колонка не используется как цена продажи.

Одинаковые исходный и нормализованный артикулы одной записи больше не создают два кандидата. Действительно разные записи с одним артикулом остаются спорными. Для старых сокращённых названий допускается подтверждение ранее импортированными полным названием и тем же артикулом; конфликт модели по-прежнему блокирует запись. Размеры дверей 1900×700 мм и 190×70 см считаются одинаковыми только при сопоставлении двери, а не произвольного товара.

Каждая успешная проверка обновляет даты, даже если значения не изменились. «В наличии» и «Товар заканчивается» означают наличие без известного количества (`stock_quantity=null`); «Под заказ» и неизвестные формулировки не считаются наличием. Сводный фиктивный остаток карточки очищается только у товаров без других каналов и без ручного учёта склада.

Полный применяемый запуск перед загрузкой изолирует предложения BANIA, не подтверждавшиеся более 48 часов. Историческая цена сохраняется, а для карточек только с BANIA включается `requires_price_confirmation`, скрывающий неподтверждённую цену и запрещающий обычное добавление в корзину. Сохраняются исходная дата наблюдения и причина проверки. Ручные цены, ручное управление складом и карточки с другими поставщиками/активной интеграцией (включая 1С) не получают эту автоматическую блокировку цены. Свежая проверенная розничная строка снимает только блокировку, поставленную этим механизмом; ручное требование подтверждения не снимается.

Ошибка скачивания не подменяется старым кешем с новой датой. Для явного аудита известного файла остаются `--price-file` и `--retail-price-file`. Неполученный/пустой розничный файл при `--sync-retail-prices` завершает запуск ошибкой. Автоматически новые карточки не создаются, спорные связи не объединяются.

Проверки: `SyncBaniaPricelistSafetyTest`, `BaniaOfferFreshnessTest`, `BaniaRetailModelGuardTest`. Используется отдельная тестовая база. Отчёты импорта: `storage/app/reports/bania/`; журнал: `storage/logs/bania-pricelist-sync.log`.
