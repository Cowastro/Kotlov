# «Чистый берег»: ежедневный прайс и понятный журнал

Прайс обрабатывается из файла, загруженного в карточке поставщика. Автоматической загрузки прайса с сайта поставщика нет.

Расписание по Минску:

| Задание | Один раз в сутки |
|---|---|
| Новый прайс: цены и остатки | 09:00 |
| Пакет создания недостающих карточек | 09:20 |
| Дополнение характеристик | 09:40 |
| Дополнение фотографий | 10:00 |
| Пакет исследования рыночных цен | 10:20 |

Лимиты пакетов и защита от одновременных повторных запусков сохранены. Задания других поставщиков и расписание BLK7 не менялись. После 09:00 новый загруженный файл ожидает следующего ежедневного запуска; это явно написано в окне загрузки. Ручной запуск команды остаётся возможным.

Если файла нет или новый файл не загружен, команда отмечает проверку как `skipped` с причиной. Журнал не сканирует весь каталог и не продвигает общий снимок изменений для такой проверки. Реальная успешная обработка с нулевыми изменениями остаётся `success`.

В журнале и TXT-выгрузке:

- указан поставщик, даже когда изменений нет;
- «Чистый берег» обозначен как загружаемый прайс XLS, а не «API / сайт»;
- фактически использованный файл архивируется при настоящем импорте;
- пропуск обозначается «Пропущено» и поясняется, что импорт не выполнялся;
- старые строки показывают правильную подпись источника без удаления истории и без угадывания, была ли конкретная старая проверка пропуском.

Регистратор журнала используется одним экземпляром в процессе команды, чтобы отметка о пропуске попадала именно в её запись. Изменения «Чистого берега» и BLK7 ограничены своим поставщиком при расчёте журнала.

Проверяются ежедневные выражения и часовой пояс, отсутствие обработки/сканирования при пропуске, архивирование загруженного файла, подписи старых записей и TXT, а также существующий импорт прайса. Полный набор тестов не запускается.
