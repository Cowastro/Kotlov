# Диагностика проведения обеспечения

Автоматическое обновление обеспечения остаётся выключенным до успешной проверки реального проведения и перехода после поступления. Успешный расчёт без записи не доказывает работоспособность проведения.

Агент 17 поддерживает адресную диагностическую задачу `onec_order_supply` с `diagnose_posting: true`, `preview: true`, точным `key`, `number`, `expected_total` и `queries: {"native_probe": "native-com"}`. Такие задачи создаются вручную для отдельно разрешённого документа; планировщик их не создаёт.

Проверка использует установленный `V83.COMConnector`, тот же логин и пароль, что OData, и базу из `default.vrd` именно локальной публикации, указанной в настройках агента. Строка базы определяется по конфигурации IIS, без перебора баз и подмены пользователя. На 64-разрядной Windows при отсутствии 64-разрядного COM используется отдельный 32-разрядный процесс. Компоненты не устанавливаются и не регистрируются автоматически.

Номер, сумма, признак проведения и отсутствие закрытия/удаления проверяются перед записью. Товарные строки не редактируются. Вызывается штатное неоперативное проведение с `ОбменДанными.Загрузка = Ложь` внутри явной транзакции. Транзакция всегда отменяется; `CommitTransaction` не используется. Подробное исключение и сообщения 1С собираются до восстановления. При зависании процесс прекращается через 120 секунд; прерванная проверка автоматически не повторяется. После проверки дополнительно читается документ через OData для сверки исходных товаров и сумм.

Полный отчёт хранится в закрытом хранилище задачи сайта (`native_probe`) и локально в `done/native-probe-<id>-result.json`. Пароль исключается из текста до JSON-сериализации. Результат не считается успешным без подтверждения проведения, отката и соответствия номера, GUID и суммы. Потерянная доставка отчёта повторяет отправку сохранённого результата, а не проведение.

Обычные строки с флагом `Обособленно` не получают общий складской остаток и не расходуют бюджет обычных строк: их обеспечение остаётся под управлением 1С.
