# Стабилизаторы напряжения: SEO и выбор, 23.11.2026

Страница: https://kotlov.by/stabilizatory-napryazheniya

## Аудит

- В базе 218 активных неархивных товаров; 182 проходят текущий публичный scope `orderable`. Числа меняются при синхронизации, поэтому не зашиты в текст.
- Старый H1 ограничивал весь ассортимент газовыми котлами. В разделе также есть мощные и трёхфазные исполнения.
- Старое описание ошибочно обещало коррекцию частоты и универсальную достаточность 200–500 ВА для бытового оборудования.
- Характеристики поставщиков заполнены неравномерно. Не преобразовывать неоднозначную «Мощность: 5» в кВт или кВА и не обещать полный подбор по характеристикам всех товаров.

## Изменения

- Сохранён адрес раздела. H1 охватывает котёл и дом; title с городом, короткое коммерческое meta description.
- Короткий верхний текст, быстрые поля существующих атрибутов, три сценария применения, памятка по выбору и шесть вопросов с ответами.
- Поля выводятся только при наличии вариантов. Единицы ВА добавляются только для групп, где все варианты явно содержат ВА/VA. Несколько выбранных вариантов сохраняются скрытыми полями, не сводятся молча к одному.
- Пустые значения быстрого подбора не превращаются в фильтр по несуществующему option_id=0. Поиск, бренд, цена и наличие сохраняются; страница сбрасывается.
- FAQPage строится из тех же данных, что видимый FAQ, только на базовой странице. ItemList отражает товары текущей страницы. Существующие canonical и noindex для параметров сохранены.
- Стили ограничены `.stabilizer-page`; на телефоне поля в две колонки, сценарии и FAQ в одну; высота полей и кнопки 44 px. Новые запросы к базе и внешние API не добавлены.
- Характеристики и цены товаров не менялись.

## Источники технических пояснений

- SVEN: https://www.sven.fi/fi/catalog/stabilizer/avr_slim_500.htm — различие полной мощности ВА и активной Вт на конкретном примере. Значения этого примера не переносились на другие модели.
- Паспорт производителя «Энергия АРС», раздел 5.1.1 и график нагрузки: https://xn--c1adkrq9eta.xn--p1ai/sites/default/files/2025-08/pasport_apc_energiya_220_230.pdf — зависимость допустимой нагрузки от входного напряжения.

## Оценка результата

Исторический ориентир из `seo-next-stage-2026-11-12.md`: за 12.10–08.11.2026 у раздела 1804 показа, 46 кликов, CTR 2,55%, средняя позиция 8,07. Это не текущие позиции и не прогноз.

После переобхода сравнить сопоставимые 28-дневные периоды Search Console: запросы «стабилизатор напряжения», «для котла», «для дома», показы, CTR, позицию и переходы с телефона. Отдельно смотреть обращения и покупки из раздела. FAQ-разметка не гарантирует расширенный сниппет или рост позиций.

Следующий содержательный этап: сверка паспортов популярных моделей, заполнение достоверных ВА/Вт, входного диапазона и фаз; затем отдельные посадочные страницы только при достаточном ассортименте и различающемся спросе. Не создавать пустые SEO-страницы из сочетаний фильтров.
