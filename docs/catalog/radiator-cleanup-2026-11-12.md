# Радиаторы: категории, импорт и характеристики — 12.11.2026

Проверены 1 283 опубликованные карточки из раздела, включая 312 карточек арматуры. Серверная выгрузка также проверена для неопубликованных/недоступных к заказу товаров. Исправление проходит по всем неархивным товарам радиаторных категорий, сохраняя ID, SKU, адреса карточек, цены и связи с поставщиками.

## Категории и импорт

Материал конкретного изделия имеет приоритет над ошибочной группой поставщика. PianoForte/Tower и Lammin BM не должны попадать в алюминиевые, Лидея ЛК/ЛУ — стальные, Lammin AL — алюминиевые. Монтажные наборы, пробки и арматура отделены от приборов. Водяные конвекторы и чугунные радиаторы сохраняют собственные категории. Масляные электрообогреватели не затрагиваются. Неопознанный материал не назначается стальным автоматически.

Единый классификатор используется импортами Rusklimat, Teplodvor и Thermostudio. В общем списке `/radiatory` арматура исключена, её отдельная категория и навигация остаются доступны. Старые URL перемещённых карточек возвращают штатный 301 на действительную категорию.

## Подтверждение данных

`resources/data/radiator-manufacturer-facts.json` — 858 точных наименований с привязкой к источникам производителя/оригинальным документам производителя, опубликованным его представителями. Числа не переносятся между похожими моделями. Данные относятся к указанному названию, не только к slug: переиспользование slug другой моделью не должно подхватить прежние характеристики.

Подтверждены: материал — 858; подключение — 667; высота — 161; ширина — 157; число секций — 78; теплоотдача с явно указанным ΔT 70 °C — 32; межосевое расстояние и глубина — 36; теплоотдача при ΔT 50/60 °C — 3. Это частичное подтверждение полей, а не 858 полностью заполненных паспортов. Полный перечень карточек без подтверждения и конфликты вынесены в `radiator-specification-audit.json`.

Источники: оригинальные каталоги Kermi therm-x2, Zehnder Charleston, Buderus Logatrend, PRADO; рекомендации ОАО «Лидсельмаш» по Лидея; документация Rifar; каталог стальных/дизайн-радиаторов Royal Thermo; точные карточки Royal Thermo на B2B Rusklimat с проверкой артикула. Для Royal Thermo Tower современная карточка поставщика противоречит паспорту по ориентации/подключению/теплоотдаче: опубликованы только материал и секционность. Не переносились давление, размеры и мощность из конфликтующих версий. Площадь не рассчитана по Вт/м², теплоотдача не пересчитывается между ΔT.

У 52 разных Royal Thermo в публичной выдаче повторялась комбинация 1026 Вт / 574 мм / 500 мм. Миграция заменяет только распознанный ошибочный шаблон у подтверждённых моделей, сохраняет остальные редакционные описания. Управляемые технические поля показываются из проверенного набора, неподтверждённые старые значения в таблице и фильтрах скрыты. Иные характеристики сохранены.

## Интерфейс и безопасность изменения

Использованы существующие фильтры, счётчики, выбранные условия со сбросом и компактные плашки карточек (не более четырёх). Материал, подключение, высота, ширина, секции, межосевое расстояние и теплоотдача имеют отдельные фильтры только с реальными значениями. Фильтрация исключена из индексации штатной политикой. В товаре — пояснение ΔT и ссылки на документацию.

Перед изменениями миграция сохраняет оригинальные значения в `storage/app/private/maintenance/radiator-catalog-2026-11-12.json` через local disk. Повторный запуск не затирает ручные изменения. Откат восстанавливает только неизменённые после миграции записи. Проверки покрывают три импорта, комбинацию фильтров и общий UI, неизвестные/конфликтующие данные, перенос с 301 и откат.

Дополнительно сверены Fondital Alustal Bimetal Super / Exclusivo Super / Calidor Super по официальному сайту: материал и явно подтверждённые размеры Alustal. Buderus BH1-W0 — термоголовка Logafix (оригинальный каталог Buderus https://www.heizungsdiscount24.de/pdf/Buderus-Logatrend-Flachheizkoerper-CV-Profil-Katalog.pdf), переносится в арматуру. Известные семейства без слова «радиатор» в наименовании тоже правильно классифицируются.

Проверка production после первой миграции выявила 19 оставшихся в корне моделей Royal Thermo: 14 COMPACT C11/C21/C22, Monoblock B и четыре алюминиевых DreamLiner/Indigo/Revolution. Дополнительная миграция завершает их перенос с отдельной резервной копией. Исправлено распознавание обозначения C22 без пробела перед типом. Алюминиевые серии подтверждены оригинальным паспортом Royal Thermo (https://thermomir.ru/files/it/2046_4971.pdf); Monoblock A — документацией B2B Rusklimat. Числа теплоотдачи старых версий не перенесены из-за различий между редакциями паспортов.

## Публичная проекция характеристик

Контроль production выявил конфликт старых полей: у COMPACT C22 оставались «Тип радиатора 11» и толщина 47 мм. Публичные таблица, описание, быстрый просмотр и SEO теперь формируются только из проверенного набора; исходные данные товара остаются в БД для разбора. Это исключает дубли гарантий, единицы без значения и неподтверждённые характеристики за пределами первоначального списка полей. Объекты для вывода клонируются, просмотр страницы не переписывает сохранённые тексты или цены.

Для 125 панельных радиаторов подтверждён тип панели по точному обозначению модели в документации Royal Thermo / PRADO / Лидея. Добавлен отдельный фильтр типов с реальными счётчиками; старые непроверенные атрибуты типов, толщин, массы и присоединений в фильтрах не используются. Номинал и размеры не извлекаются из URL или случайных цифр артикула.

## Дополнение недостающих характеристик (12 ноября 2026)

Повторно проверена текущая публичная выдача: 967 позиций. Дополнены недостающие поля 758 карточек, без изменения цен, остатков, ID и исходных описаний в БД. После дополнения теплоотдача с явно объявленным температурным напором есть у 749 позиций: 608 значений для целого прибора и 141 для секции. Полные размеры собранного прибора (высота, ширина, глубина) подтверждены у 609 позиций. Отдельные параметры: высота 790, ширина 652, глубина 747, подключение 672. Это не означает, что каждый из этих товаров имеет полный паспорт.

Проверены оригинальные таблицы Kermi РФ (подписанный паспорт, полные артикулы с Y), Kermi therm-x2 Германия / Plan-Line, Zehnder Charleston CIS 2024–25, совместные таблицы Лидея ЛК/ЛУ, Rifar 08.2026 / Tubog 03.2026, текущие паспорта Royal Thermo и точные страницы B2B с заводским артикулом, Buderus K/VK-Profil, PRADO Classic/Universal 300/500, Fondital Super и Nova Florida Extrathermserir Super B4 / Libeccio C2. В manifest каждого дополнения записаны URL, страницы PDF (с единицы; Technical data для HTML), список полей и условие сопоставления. Отпечатки загруженных документов сохранены отдельно.

Принципиальные ограничения:

- Для Zehnder и общих карточек Rifar нет заказанного количества секций/кода подключения. Показаны только паспортные значения секции; ширина секции не выдается за ширину радиатора.
- Для Tubog D1 нижнее подключение подтверждено схемой производителя; ширина рассчитана только по его явной формуле L = n×46+6. Тепловую мощность секции не умножаем для выдачи неподтверждённого номинала сборки.
- Старые Kermi Kompakt без указания therm-x2 не получают теплоотдачу из каталога другой редакции. Строки с противоречивыми номиналами в оригинальном каталоге и название FKO 224004800 вне размерного ряда остаются без теплоотдачи.
- Для Royal Thermo COMPACT используется актуальный паспорт: C22 500×1600 — 3599 Вт при ΔT70, глубина 97 мм; старые 3528 Вт / 100 мм не переносятся.
- Для PRADO номиналы взяты из паспорта Classic/Universal, не Style; условие ΔT70 подтверждено рекомендациями изготовителя. Для Infinity паспорт подтверждает только 500, не 300. Паспорт STI RUS не подменяет китайские Classic/S500A2.
- У Nova Florida опубликован подтвержденный ΔT50 без пересчета в ΔT70. Значения разных температурных напоров не смешиваются в фильтре.

218 позиций остаются без однозначно подтвержденной теплоотдачи. Полный список недостающих полей и причин находится в `resources/data/radiator-specification-audit.json`, включая неопределённые исполнения и конфликтующие источники. Список — очередь проверки паспортов, не повод заполнять по аналогии. В текущую выдачу также попали две позиции креплений; их технические параметры радиаторами не считаются.

Стили карточек и фильтров общие для каталога. На плашках явно видны ΔT и «Вт/секц.». Добавлен отдельный фильтр полной теплоотдачи ΔT50 и недостающие типы панелей 12/11А/30А. Теплоотдача секции не участвует в фильтрах мощности целого прибора. В таблице видны размеры, все подтверждённые режимы и пояснение исполнения подключения. Новая миграция не требуется: проверенный набор применяется существующей публичной проекцией, исходные данные сохраняются.
