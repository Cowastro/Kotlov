# Настройка партнёрских уровней

В Filament откройте «B2B → Уровни партнёрской программы». Создайте три уровня с порядком от 1 до 3. Четвёртая позиция доступна для дальнейшей настройки. Стартовый уровень оставьте без условий. Для следующих уровней заполните условия перехода, которые должны выполниться одновременно.

Для каждого условия задайте отдельный скользящий период в месяцах. В расчёт входят заказы компании с датой создания в этом периоде, статусом оплаты `paid` и статусом заказа, отличным от `cancelled`. Оборот берётся из `total`. Оценка выполняется ежечасно и доступна вручную через `php artisan partners:evaluate-levels`. Достигнутый уровень сохраняется при снижении оборота.

В разделе «Выгоды» настройте отдельно оптовые цены, отсрочку платежа, приоритет в каталоге монтажников, заявки с сайта и бонус за объём. Пустые поля скрыты. Приоритет в каталоге и заявки с сайта отображаются только монтажным организациям. Эти поля определяют, какие условия видит партнёр в кабинете. Применение коммерческих условий и начисление бонусов выполняются отдельно.
